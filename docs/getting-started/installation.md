# Installation
## Prerequisites

- Anaconda or Miniconda
- CUDA 12.1 compatible GPU
- Blender 3.5.1 (will be installed by blenderproc automatically)

## Installation
By running the setup script, it will do these steps:

1. Create conda environment
2. Install dependencies
3. Install dependencies in blender

```bash
cd UAV-Data-Generation
bash scripts/setup.sh
```
