# Post-processing
## Generating COCO annotation & Splitting into subsets
In demo, we use **300** samples for each weather. So, there are **1500** samples in the dataset.

If we split the samples into **1000** for training and **500** for validation, the validation ratio will be **0.3333**.

!!! info "Info: Scale-invariant"
    The annotations are invariant to the size of processed images.

    In other words, if the size of processed images are different from the `foreground.json` ([generated by blender](../getting-started/uav-generation.md#running-with-the-demo-config)), the script will resize the annotations automatically.

!!! note "Note: Default script behavior"
    By default, the final folders will be original images folder (specified in `--images-dir`) and `annotations`.
    
    If you want to change the output folder, you can specify the option `--images-out-dir` and `--annotation-out-dir`.
    
    For example, change annotations folder, `--annotation-out-dir annotations_stylized_cut_weather_anti_uav_CUT_load_845_crop_768`.

Please fill the arguments `<...>` first.

```bash
conda activate uav_data_generation

# use stylized images as our final images
python scripts/post_processings/post_process.py \
    "<the folder contains UAV datasets>/Weather_Anti_UAV_T" \
    --images-dir stylized_cut_weather_anti_uav_CUT_load_845_crop_768 \
    --images-out-dir images \
    --val-ratio 0.3333

# OR

# use harmonized images as our final images
python scripts/post_processings/post_process.py \
    "<the folder contains UAV datasets>/Weather_Anti_UAV_T" \
    --images-dir harmonized \
    --images-out-dir images \
    --val-ratio 0.3333

```

For more details about how to use it, run with `-h` option or see the arguments in the script, `scripts/post_processings/post_process.py`.

For more details about the formats in the entire pipeline, see [Dataset in Design](../design/dataset.md).

## Validating COCO annotation

For example, we want to validate the COCO annotation of stylized images.

```bash
conda activate uav_data_generation

python scripts/post_processings/validate_coco_dataset.py \
    "<the folder contains UAV datasets>/Weather_Anti_UAV_T" \
    --images-dir stylized_cut_weather_anti_uav_CUT_load_845_crop_768
```

For more details about how to use it, run with `-h` option or see the arguments in the script, `scripts/post_processings/validate_coco_dataset.py`.
